# Concept Illustrations

[Back to the visual study guide](../../README.md#visual-study-guide)

These original SVG illustrations accompany the question banks. They use descriptive text and fixed high-contrast colors, and remain readable without Mermaid support. Each SVG includes a title and text description. The repository's [MIT License](../../LICENSE) applies to these original assets; linked sources retain their own terms.

| Illustration | Meaning and source |
| --- | --- |
| [Confusion matrix](confusion-matrix.svg) | A hypothetical 100-case example explaining precision and recall. Concept: [Google's classification metrics guide](https://developers.google.com/machine-learning/crash-course/classification/accuracy-precision-recall). |
| [Causal attention mask](causal-attention.svg) | Allowed query-to-key connections, not measured attention weights. Concept: [Vaswani et al., Attention Is All You Need, section 3.2.3](https://arxiv.org/abs/1706.03762). |

Architecture and workflow diagrams live as editable Mermaid blocks beside their questions. Captions distinguish general concepts from scenario-specific design choices and link supporting references. No third-party image files are embedded here.
