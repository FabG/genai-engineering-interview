# Concept Illustrations

[Back to the visual study guide](../../README.md#visual-study-guide)

These original SVG illustrations accompany the question banks. They use descriptive text and fixed high-contrast colors, and remain readable without Mermaid support. Each SVG includes a title and text description. The repository's [MIT License](../../LICENSE) applies to these original assets; linked sources retain their own terms.

| Illustration | Meaning and source |
| --- | --- |

## Edit or regenerate

- Twenty diagrams have editable [Mermaid source files](source). Export with Mermaid CLI and [mermaid-config.json](source/mermaid-config.json) for portable SVG text and the repository colors.
- Twelve plots are generated by [generate_plots.py](source/generate_plots.py), which uses a fixed seed and synthetic data. Install `matplotlib` in a separate environment, then run `python assets/diagrams/source/generate_plots.py` from the repository root.
- The question notebooks retain their standard-library-only exercise code; visual regeneration tools are optional and separate.
- Captions and alt text live in the question banks. Keep those explanations synchronized when changing an illustration.
